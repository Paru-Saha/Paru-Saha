# Paru Saha — GitHub Profile Setup

## 1. Find your GitHub username

Your **GitHub username** is required for the special profile repository.

Your profile repository must have exactly the same name as your GitHub username.

Example:

```text
GitHub username: paru123
Repository: paru123
```

GitHub's official documentation confirms that the repository must be public,
match your username, and contain a non-empty `README.md`.

## 2. Create the repository

On GitHub:

1. Click **New repository**
2. Enter your exact GitHub username as the repository name
3. Select **Public**
4. Enable **Add a README file**
5. Create the repository

## 3. Replace the username

Open `README.md` and replace every occurrence of:

```text
YOUR_GITHUB_USERNAME
```

with your real GitHub username.

This is needed for the GitHub statistics and activity graph.

## 4. Add your real projects

After you have repositories you want to showcase, replace the placeholder
projects in the **Featured Projects** section with your actual repositories.

Do not add projects, awards, hackathons, or technologies that you have not
actually worked with.

## 5. Pin your best repositories

After creating useful public repositories, pin your strongest projects on
your GitHub profile so visitors can find them quickly.
